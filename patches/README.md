База: **«База Мастера» 1.13.0 → 1.13.1** · Node v20.20.2

**Финальный масштаб:** библиотека инструкций выросла с 38 до **82 записей** (дописаны

`data/parts.json` сошлись **побайтово** с деревом, где правки вносились вручную.

```bash

for p in patches/*.patch; do git apply "$p"; done
```

Нет `git apply` — в `patches/modified/` лежат **готовые файлы целиком**
