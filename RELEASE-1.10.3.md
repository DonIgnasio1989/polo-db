## Найденные баги и исправления

### 1. Печать «Списка покупок» молча падала при блокировщике всплывающих окон — `pShop()` (`js/app.js`, ~6326)

`window.open('', '_blank')` при заблокированных попапах возвращает
`null`, и `pShop()` падал с TypeError **без единого сообщения** —
пользователь нажимал «🖨 Печать», и не происходило ничего. Особенно
актуально на телефонах (агрессивные блокировщики, настройки Safari).
В `printIssueChecklist()` и `printVinCard()` защита уже была — в
`pShop()` её пропустили.

```js
// стало (как в остальных двух печатях):
if (!w) { toast('Браузер заблокировал всплывающее окно — разрешите его для этого сайта', 'danger'); return; }
```

### 2. Пустая дата в баннере «Последнее ТО» — `oShopList()` (`js/app.js`, ~6218)

С 1.10.1 расчёт ТО может идти **по пробегу** (`lastKm`) без даты —
это легальный сценарий («дату не помню, пробег на ТО знаю»). Но баннер
в списке покупок печатал `📅 Последнее ТО: <b></b> · …` — пустое место
в жирных скобках. Теперь без даты показывается пробег:

```
📅 Последнее ТО: на 240 000 км · Следующее через 10 874 км (~321 дн.)
```

Дата по-прежнему в приоритете, когда указана. Заодно устранена
потенциальная ловушка: вычисление подписи перенесено внутрь `if (t)`
(при `nextTO() === null` старый вариант обращения к полю упал бы).

### 3. iOS Safari: тап по поиску зумил всю страницу (`css/app.css`, конец файла)

iOS Safari **принудительно приближает страницу** при фокусе поля ввода
с `font-size < 16px`. Мобильный поиск `.sr` на ≤480px — `.78rem`
(≈12,5px), поля модалок тоже ниже порога. Каждый тап по поиску на
iPhone «наезжал» интерфейсом, обратно — только щипком.

Исправление — только для iOS (Android/десктоп не затрагиваются, там
авто-зума нет), через iOS-индикатор `@supports (-webkit-touch-callout: none)`:

```css
@supports (-webkit-touch-callout: none) {
    input:not([type="checkbox"]):not([type="radio"]):…:not([type="date"]),
    textarea { font-size: 16px !important; }
    .sr { line-height: 1.2 !important; }
}
```

Поля `date/time` не трогаем — там нативный пикер без клавиатуры и без
зума. Компактный дизайн Android сохранён.

### 4. `100vh` без `dvh` — низ приложения и модалок уезжал за панель браузера (5 мест в `css/app.css`)

На iOS Safari (и части Android) `100vh` включает **скрытую** панель
браузера: реальная видимая область ниже. Итог — нижние кнопки модалок
(«💾 Сохранить», «🖨 Печать») и подвал приложения оказывались за
панелью. Добавлены progressive-enhancement фолбэки (старые браузеры
dvh не знают и останутся на vh):

| место | было | стало |
|---|---|---|
| `body` (~243) | `height: 100vh` | + `height: 100dvh` |
| `.mw` (~1308) | `height: 100vh` | + `height: 100dvh` |
| `.mdl` (~3247) | `max-height: calc(100vh - 48px)` | + `calc(100dvh - 48px)` |
| `#licgate .gate-inner` (~3999) | то же | + dvh |
| `#upmo .mdl` (~6462) | то же | + dvh |

### 5. Тач-цели кнопок карточки VIN — `.gi-btn` (~30px)

Шесть кнопок действий в карточке VIN (✎ Уточнить, 📋 Оснащение,
🛒 Расходники ТО, 📱 QR, 📍 Где коды, 📤 Экспорт) на мобильных имели
высоту ~30px — ниже стандарта тач-целей (38–44px), промахиваться легко.
В мобильном медиа-блоке: `padding: 10px 11px; min-height: 40px`.
