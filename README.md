# 🔧 VW Polo / Caddy 6N — База Мастера

Неофициальный каталог запчастей, регламентов и инструкций по автомобилям **VW Polo/Caddy (6N1, 6N2, Classic, Estate, Caddy)** 1995–2003 гг.

**Живая версия:** [https://donignasio1989.github.io/polo-db/](https://donignasio1989.github.io/polo-db/)

---

## 📖 О проекте

Веб-приложение работает **офлайн**, хранит данные в браузере (IndexedDB + localStorage), подтягивает базу из JSON-файлов и не требует установки. Открывается на компьютере, планшете, телефоне. Можно добавить на главный экран как приложение.

### Возможности

- 📦 **Каталог запчастей** — 170+ позиций по двигателю, топливной, зажиганию, охлаждению, тормозам, подвеске, КПП, электрике, кузову, салону
- 🔧 **Аналоги и доноры** — кросс-совместимость с VW Lupo, Seat Arosa, Skoda, LADA, ВАЗ, Москвич, ГАЗ, Audi
- 🎯 **Меню в стиле ETKA** — группы 1-0 как в оригинальном каталоге Volkswagen
- 📖 **Журнал обслуживания** — история работ с датой, пробегом, стоимостью, привязкой к деталям
- 🛠 **Виджет ТО** — цветной индикатор «до следующего ТО осталось N км / N дн.»
- 🛒 **Список покупок на ТО** — чекбоксы, экспорт CSV, печать
- 🔍 **Поиск** по OEM, названию, аналогам, заметкам
- 🌐 **Магазины в один клик** — Exist, Autodoc, Avito по любому артикулу
- 📥 **Импорт/Экспорт JSON** — резервные копии, обмен базами между пользователями
- 🌓 **Тёмная / светлая тема**
