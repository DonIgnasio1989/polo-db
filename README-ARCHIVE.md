## Два способа применить

**А — патчами (на ваш репозиторий):**
```bash
cd <репозиторий>
for p in patches/*.patch; do git apply "$p"; done
node tests/test_instructions.js && node tests/test_1106.js && node tests/test_sections_1110.js
node tools/build-instructions.js --check --verbose     # 82 записи, 0 ошибок, все артикулы найдены
node tools/build-instructions.js --apply               # 407 карточек / 9 279 строк
node tools/build-parts.js && node tools/dedup.js --src data-src --out restore --apply
node tools/audit-parts.js && node tools/validate-data.js
node tools/check-engines.js                            # S52 R0 A63 O0 N1 X11 (--strict → exit 0; A: IN44/OUT15/CONFLICT4; N1 = AHV — внешних данных не существует)
```

**Б — готовым (без пересборки):**
```bash
cp -r merged-data-src/*  <репозиторий>/data-src/       # уже со слиянием
cp -r server-dist/*      <корень веб-сервера>/         # готовая поставка
```
