# vin-dump/ — исходники базы VIN (дамп ETKA)

Материалы из сборки `vin-db.meta.json` (2026-10-17): сканировано **1 172 391** файлов дампа ETKA,
из них под каталоги 6N/6V/9K/9U подошло **13 359** уникальных VIN.

## Файлы

| Файл | Что это |
|------|---------|
| `vin-db.meta.json` | Метаданные прогона генератора (даты, счётчики по моделям) |
| `filtered-vins.txt` | Итоговый список VIN (13 359 шт., по одному на строку) |
| `filtered-files.txt` | Пути к исходным `.txt`-файлам дампа, из которых собран список (Windows-пути `.\VIN.txt`) |

Распределение по моделям (из meta):

- Polo (6N1) — 4 933
- Polo (6N2) — 3 800
- Polo Classic/Variant (6V) — 109
- Caddy Pickup (9U) — 8
- Polo (6N) — 24

## Что сейчас в `data/vin-db.json`

Из `filtered-vins.txt` сгенерированы **пустые записи** вида `{"vin": "WVW..."}` — приложение
распознаёт сам факт «этот VIN есть в дампе ETKA», но оснащение (мотор, КПП, краска, PR-коды)
пока не показывает: кнопка «📋 Оснащение (PR)» объясняет это подсказкой.

## Как получить полный vin-db.json

Исходные `.txt`-файлы дампа (пути в `filtered-files.txt`) остались на машине, где делался прогон.
Запустите ваш генератор повторно по тому же входу, но **без** флага, отсекающего содержимое
(в meta стоит `"scan_only": false`, `"pr_dict_codes": 0` — словарь PR в прогоне не собирался),
и положите результат в `data/vin-db.json`. Ожидаемый формат записи:

```json
{
  "vin": "WVWZZZ6NZYX123456",
  "engine": "AEX",
  "gearbox": "085",
  "gearbox_code": "CHL",
  "paint": "J2",
  "roof_color": "J2",
  "equip_code": "41",
  "prod_date": "1999-04-14",
  "pr": ["0EA", "1ZB", "G0C"]
}
```

Допустим и старый вариант со склейкой `trim` (`"J2J241"` = кузов J2 / крыша J2 / оснащение 41) —
приложение разбирает оба формата (`vinDbColors`).

Описания PR-кодов уже подключены: `data/pr-codes.json` (1 723 кода).
После подмены vin-db.json автоматически заработают:
- автозаполнение мотора/КПП/краски/даты при добавлении VIN и в «✎ Уточнить данные»;
- «📋 Оснащение (PR)» с группировкой по категориям;
- PR-коды на персональной наклейке в «📍 Где коды».
