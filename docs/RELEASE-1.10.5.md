# RELEASE 1.10.5 — «Полоска расходов за год больше не вылезает за виджет»

**Дата:** 2026-10-18
**Предыдущая версия:** 1.10.4

## Запрос владельца

> «в журнале и расходах полоска расходов за год вылазит за пределы виджета»

Речь о карточке **«📖 Журнал и расходы»** в кабинете «Моя машина»: под
списком последних записей идёт диаграмма расходов по годам — год,
полоска, сумма. Сумма (а на узкой карточке и сама полоска) выходила за
правый край карточки.

## Причина (геометрия, а не данные)

Ряд бара был **flex-контейнером**, а заливка получала ширину в процентах
**от ширины всего ряда**, а не от «дорожки»:

```
.dc-bar   { display: flex; gap: 6px; }          /* год | заливка | сумма */
.dc-bar-y { width: 34px;  flex-shrink: 0; }     /* не сжимается */
.dc-bar-f { height: 10px; flex-shrink: 0; }     /* не сжимается, width:N% от ВСЕГО ряда */
.dc-bar-v { … }                                 /* некуда деваться — уходит за край */
```

Для года-максимума `width:100%` = полная ширина ряда, то есть заливка
заняла всё место, а сумма вместе с зазором `gap` вытолкнулась за границу
карточки. Сжиматься было нечему: у года и заливки стоял `flex-shrink:0`,
у суммы — `white-space` по умолчанию, но колонки для неё фактически не
было. Чем крупнее расходы и чем уже карточка (телефон, узкая колонка
сетки `dash-grid`), тем сильнее вылезало.

## Что сделано

### 1. Ряд бара — сетка из трёх колонок (`css/app.css`, `.dc-bar*`)

```
.dc-bar   { display: grid;
            grid-template-columns: 34px minmax(40px, 1fr) minmax(0, max-content);
            align-items: center; gap: 6px; max-width: 100%; }
.dc-bar-t { height: 10px; border-radius: 3px; background: var(--hv);
            overflow: hidden; min-width: 0; }   /* ← новая «дорожка» */
.dc-bar-f { display: block; height: 100%; max-width: 100%; }
.dc-bar-v { white-space: nowrap; overflow: hidden; text-overflow: ellipsis;
            text-align: right; min-width: 0; max-width: 100%; }
```

* Процент заливки теперь считается **от её дорожки** (`.dc-bar-t`),
  поэтому за границах дорожки он не выйдет физически;
* дорожка видна на всю ширину колонки — диаграмма читается как диаграмма
  даже при маленьких суммах;
* сумма живёт в **собственной колонке** и при нехватке места сокращается
  многоточием, а не вылезает; точное значение остаётся в подсказке;
* год (`б/д`, `2026`) тоже не растягивает ряд: `ellipsis` в своей колонке.

### 2. Разметка бара — `rDash()` (`js/app.js`, ~785)

```js
h += '<div class="dc-bars">' + years.slice(-5).map(y => {
    const tot = yearTot(y);
    const w = Math.min(100, Math.max(4, Math.round(tot / maxYear * 100)));
    const cs = Object.keys(spend[y]).sort();
    const val = cs.map(c => fP(spend[y][c], c)).join(' + ');
    return '<div class="dc-bar" title="' + escA(y + ': ' + val) + '">'
        + '<span class="dc-bar-y">' + esc(y) + '</span>'
        + '<span class="dc-bar-t"><i class="dc-bar-f" style="width:' + w + '%"></i></span>'
        + '<span class="dc-bar-v">' + esc(val) + '</span></div>';
}).join('') + '</div>';
```

* `Math.min(100, …)` — процент больше никогда не превышает 100;
* сумма года выводится через `fP()`, то есть **всегда со знаком валюты**
  (было: `18450` без ₽, если в году не было чисто рублёвых записей —
  показывалась голая сумма «в кучу»);
* если в году несколько валют — честная разбивка `3 200 ₽ + 150 $`
  (порядок валют по алфавиту, не зависит от порядка записей в журнале);
* значение и подсказка экранируются (`esc` / `escA`) — как и раньше.

### 3. Ничего больше не трогали

`data/*`, печать, ТО, журнал (`rLog`) и логика подсчёта расходов по годам
не изменились: правка чисто визуальная, данные те же.

## Как проверить руками

1. Открыть приложение, «Моя машина» → карточка «📖 Журнал и расходы».
2. Завести пару записей журнала с разной стоимостью (и одну в другой
   валюте) — полоски пропорциональны, суммы целиком внутри карточки.
3. Сузить окно до телефона: сумма не вылезает, при крайней узости
   сокращается многоточием, полное значение — во всплывающей подсказке.
