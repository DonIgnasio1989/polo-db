# «База Мастера» против зарубежных аналогов

**Дата:** 2026-10-24 · **Версия приложения:** 1.12.0
**Зачем:** понять, где мы сильнее, где слабее, и забрать чужие удачные решения.
Всё, что удалось внедрить сразу, — внедрено в 1.12.0 (помечено ✅).
Что требует вашего решения — в разделе «Не взяли (пока)».

Сравниваем не «магазин против магазина», а по задачам мастера:
подобрать деталь → понять применимость → найти причину неисправности →
затянуть правильным моментом → записать работу.

## 2. Где мы объективно сильнее

1. **Оффлайн и «одно окно».** ALLDATA DIY, erWin, autodoc — онлайн-сервисы с
   подпиской; в гараже без сети они бесполезны. У нас PWA + IndexedDB + Service
   Worker: каталог, справочники и журнал работают в подвале без сигнала.
2. **Глубина применимости.** Фильтры по коду мотора, буквенному коду КПП,
   кузову, поколению **и PR-кодам** одновременно. У RockAuto/autodoc подбор
   идёт по «год-модель-мотор», буквенных кодов КПП и PR-кодов там нет.
3. **PR-оснащение по 13 359 конкретным VIN** из дампа ETKA. Публичные
   аналоги дают расшифровку VIN по одному запросу (erWin), готовой базы
   «VIN → мотор/КПП/краска/124 PR-кода» нет ни у кого из перечисленных.
4. **Аналоги с транзитивным замыканием** (union-find по сегментам OEM и
   кроссам) + база знаний + голоса. RockAuto показывает кроссы, но цепочку
   «аналог аналога» не строит и офлайн не работает.
5. **Связка «справочник → каталог».** С 1.12.0 код ошибки ведёт кнопкой прямо
   в выдачу деталей. Ни Ross-Tech Wiki, ни ALLDATA так не умеют: статья и
   магазин у них живут раздельно.
6. **Цена и независимость.** Подписки ALLDATA/erWin стоят денег и привязаны к
   региону; наша база — файл на вашем сервере.

## 4. Что взяли у них в 1.12.0

### 4.1 Ross-Tech Wiki → поиск по коду и структура «симптомы / причины / решения»

У Ross-Tech каждая страница кода построена по шаблону **Possible Symptoms →
Possible Causes → Possible Solutions → Special Notes** [1](https://wiki.ross-tech.com/wiki/index.php/Fault_Code_(Template/Explanations)),
а поиск по коду мгновенный.

**Взяли:**
* мгновенный фильтр во всех 10 справочниках (`rSec`): ищет по всем колонкам,
  все слова запроса обязательны, `ё`=`е`, регистр не важен. Счётчик
  «показано N из M», очистка по `Esc`;
* колонка «Причина» → **«Симптомы / причина»**, у 35 частых кодов дописаны
  симптомы («троит, MIL мигает под нагрузком», «заводится и глохнет через
  1–2 с», «плавают обороты после сброса АКБ», «вентилятор крутит постоянно»);
* сортировка кликом по заголовку: числа — как числа («9» < «10» < «100»),
  текст — по-русски; моменты вида «40 Нм → 60 Нм» сортируются по первому числу.

### 4.2 ALLDATA / Haynes → читаемость длинных таблиц

Длинные таблицы в печатных и онлайн-мануалах читаются за счёт фиксированного
заголовка и чередования строк.

**Взяли:** «липкая» шапка (`position: sticky` внутри собственной области
прокрутки `max-height: min(72vh, 900px)`), зебра, подсветка строки при
наведении, адаптив для узких экранов. Без своей области прокрутки sticky не
работает — обёртка с `overflow-x:auto` сама становится контейнером прокрутки.

### 4.3 RockAuto → переход от статьи к конкретной детали

RockAuto силён тем, что поиск по номеру сразу даёт «что это и чем заменяется»
[2](https://www.rockauto.com/en/partsearch/)[3](https://www.rockauto.com/help/?page=1).
Прямого аналога «код ошибки → детали» нет ни у кого.

**Взяли (и расширили):** в «Диагностике» появилась 5-я колонка **«Детали
каталога»** — кнопки, которые выполняют поиск по каталогу:

```
P0301  Пропуск: цилиндр 1   →  [свечи 🔎] [катушка зажигания 🔎] [форсунки 🔎]
P1143  Расчёт нагрузки: …    →  [ДМРВ 🔎] [впускной коллектор 🔎]
P0685  Главное реле J271     →  [главное реле J271 🔎]
```

Ссылки работают у **82 кодов из 100** (41 уникальный запрос). Формат ячейки —
`метка|#q:запрос`, несколько ссылок разделяются `;;`; есть и `метка|#sec:Id`
для перехода между справочниками, и прежний `метка|https://…`.

**Гарантия от «мёртвых» ссылок:** `tools/validate-data.js` прогоняет каждый
запрос через тот же алгоритм, что и `mP()` в приложении (все слова запроса +
словарь синонимов `SYNONYMS`), и **блокирует сборку**, если запрос не находит
ни одной детали. На первой же проверке это дало 7 нерабочих ссылок и вскрыло
пробел каталога: деталей наддува и вторичного воздуха нет вовсе — поэтому у
P1235/P1247/P1252/P1420/P1425 ссылок не будет, пока не появятся позиции.

### 4.4 wheel-size.com → раздел «Колёса и шины»

wheel-size.com держит эталонную базу посадочных параметров (PCD, DIA, ET,
размеры шин) по годам и модификациям [4](https://www.wheel-size.com/),
а для Polo III (6N) параметры подтверждены независимо: **4×100, DIA 57.1 мм,
ET35–40** [5](https://us.hubcentric-rings.com/car_models/volkswagen/polo/),
штатный размер 175/65 R13 с альтернативами 185/55 R14 и 195/45 R15
[6](https://www.tiresizehelp.com/Tires/1995/Volkswagen/Polo%20%286N1%29/60%201.4).

**Взяли:** новый раздел **🛞 «Колёса и шины»** (25 строк):
* посадка: PCD 4×100, DIA 57.1, ET35–40, крепёж — **болты M12×1,5** (не гайки),
  момент **110 Нм**, сфера R14, 16 шт; артикулы `3A0 601 139` и `WHT 003 261`;
* заводские диски 4.5J×13 … 6.5J×16, момент винта диска 10 Нм, гайки ступиц;
* расшифровка маркировки шины и таблицы индексов нагрузки/скорости;
* строка «⚠ Что нельзя»: M14×1,5 и диски 5×100/5×112 (Golf IV, Passat B5);
* **все 10 размеров шин с давлениями собираются автоматически из карточек
  каталога** (категория «Шины»), отсортированы по диаметру — справочник
  физически не может разъехаться с данными; у трёх «бедных» карточек
  (175/65 R14, 185/60 R14, 185/55 R15) честно написано, что индексов и
  вылета в них нет;
* строка про поколения: 13″ — преимущественно 6N1, 14–15″ — 6N2, с оговоркой
  «ориентир, а не правило — точный размер по наклейке».

Момент 110 Нм для Polo 6N **и** Caddy 9K подтверждён таблицей производителя:
«Caddy (9KV, 9KVF, 9U, 14D) / Polo (86C, 6N, 6NF, 6KV) — 110 Nm»
[7](https://www.reifendirekt.at/drehmoment-alufelge.html) — этим же закрыта
ошибка прежней таблицы («Caddy 140 Нм»).

### 4.5 Мелочи, подсмотренные по ходу

* У Ross-Tech и OBD-Codes подписи ссылок короткие, а URL открывается в новой
  вкладке с `rel="noopener noreferrer"` — оставили и добавили то же для
  кнопок-поисков.
* У Haynes таблицы рассчитаны на печать — наши справочники печатаются штатным
  `@media print` (правила идут после блока справочников, поэтому имеют приоритет).

## 5. Не взяли (пока) — и почему

### 5.1 Spritmonitor / Fuelly: учёт топлива и фактический расход

Главная фишка Spritmonitor — «сравните свой расход с другими владельцами той
же модели» [8](https://www.spritmonitor.de/en/), у Fuelly — динамика MPG и
стоимость эксплуатации [9](https://www.fuelly.com/).

**Почему не сделали сразу:** в записи журнала нет объёма заправки —
`{date, km, title, items, cost, currency, shop, notes, vin}`. Нужна правка
схемы (поле `fuel` в литрах + признак «полный бак»), иначе расход не посчитать
честно: Spritmonitor считает по методу полного бака, частичные заправки
помечаются отдельно.

**Предложение (готовый дизайн, ~1 день работы):**
1. в модалку записи журнала — поля «Литры» и чекбокс «полный бак»;
2. в кабинете «Моя машина» — виджет «Расход»: средний по записям с полным
   баком, динамика по месяцам, сравнение с нормой;
3. нормы расхода — новый справочник `FuelNorms` по кодам моторов (данные
   `ENGINES` уже есть: объём, мощность, топливо);
4. сигнал «расход вырос на 15 % за 3 месяца» — ранний признак неисправности
   (обычно это P0171/P1136, которые у нас уже в справочнике).
5. Сравнение «с другими владельцами» возможно только внутри вашей базы
   (несколько машин в гараже) — внешних данных нет, и это правильно: чужие
   цифры без контекста врут.

### 5.2 ALLDATA / erWin: TSB и отзывные кампании

Официальные бюллетени и отзывы по 6N закрыты; отдаёт их только дилер по VIN.
Полумера — строка-инструкция в «Диагностике»: «проверить отзывные кампании по
VIN у дилера или на официальном сайте VW вашей страны». Могу добавить, если
скажете, какой регион указывать (РФ / ЕС) — ссылка различается.

### 5.3 RockAuto: цены и наличие

Требует интеграции с поставщиками (API/парсинг) и решения по валютам и
юрисдикции. У приложения уже есть поле `shopUrl` у детали и ссылки в
`SH` (exist.ru, autodoc.ru, avito) — этого достаточно, пока не появится
договорённость с поставщиком.

### 5.4 7zap/ETKA: взрыв-схемы

Права на изображения. Реалистичный путь — не копировать схемы, а держать
ссылки на архивы (что уже сделано в разделе «Электросхемы»: 12 строк, все
ссылки `vwts.ru` отвечают 200).
